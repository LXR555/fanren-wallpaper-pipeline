# 凡人修仙传 · 壁纸流水线

从 B 站视频链接到 4K 壁纸，再到相册网页 / 桌面 APP 的一条完整本地流水线。

> 图片素材版权归《凡人修仙传》动画出品方所有，**本仓库只记录方法与工具，不含任何动画截图**。

![工作流](workflow.png)

## 七个阶段

| # | 阶段 | 谁做 | 耗时 | 做什么 |
|---|---|---|---|---|
| 1 | 取材 | 自动 | ~15 秒 | 定集号 → yt-dlp 拉 480p → ffmpeg 抽 1fps → 预筛偏暗/字幕 → 拼 6 张审图墙 |
| 2 | 选帧 | **人** | 5–10 分钟 | 看墙挑 14–18 个时间点（唯一不可自动化的一步） |
| 3 | 精取 4K | 自动 | ~30 秒 | 浏览器 CDP 按秒截 4K 原帧 → 去掉 B 站站标 |
| 4 | 命名入库 | 自动 | ~6 秒 | 按规范改名 → 拷进 `site/img` → 重建 `data.js` / 缩略图 |
| 5 | 网页 | 交付物 | — | 墨黑 + 金、三列大卡、全屏大图（两侧相邻图 + 底部胶片条） |
| 6 | 桌面 APP | 交付物 | — | Tkinter 壁纸管家：单击看大图、双击设壁纸、悬浮球换图 |
| 7 | 图标 | 自动 | ~30 秒 | 从 4K 帧裁圆形头像，一次派生 favicon / PWA / 窗口图标 |

## 为什么快

旧做法让浏览器以 1.5 倍速**真实播放**一遍 20 分钟正片（约 12 分钟），抽帧只是副产品。
改成「下载低码率源 + ffmpeg 顺序解码」后，同样的 1010 帧只要 **14.5 秒**——把「播放时长」从流程里删掉了。

## 工具链

| 环节 | 工具 |
|---|---|
| 下载 | yt-dlp（B 站大会员画质，cookie 经 CDP 导出，绕开浏览器加密） |
| 抽帧 / 转码 | ffmpeg |
| 取 4K | Edge CDP（`scan3.mjs`），按秒定位 |
| 图像处理 | Pillow / numpy / OpenCV |
| 修图实验 | LaMa ONNX（去字幕，单图修补有上限） |
| 语音 | SenseVoice 本地模型（听写，可选） |
| 发布 | gh CLI |

## 工作流里的判定规则（节选）

- 留存率：女性角色 69%、半身 62%、正脸 56%、远景只有 14%
- 银月优先级最高（相册占一半以上），"可爱三件套"：有表情 + 有手势/动作 + 狐耳或与白狐同框
- 站标一票否决；同一镜头 10 秒内只取 1 张
- 像素评分只能粗排（237 个决策上 AUC 0.64），**终选永远靠人看图**
