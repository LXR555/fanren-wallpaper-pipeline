### 2.1 预览点击失效的根因（已修）

Tk 的 Canvas 里，**widget 级绑定（`cv.bind`）先于 item 绑定执行**。
原来的"点背景关闭"挂在 widget 上，于是点小图时先触发关闭、预览直接消失，看起来像"点了没反应"。
改成：背景用一个铺满画布的 `bg` 图元承接点击，其余缩略图各自带一块加大 10px 的透明热区，
item 绑定返回 `break` 后就不会再触发背景关闭。
